# Intent Proxy App

**定位**：一个**独立的第三方应用** (Autonomous App)。它不再是 AgentOS 的所谓“核心模块”或“内置组件”，而是运行在 AgentOS 微内核之上的一个标准用例。

## 架构职责
此 App 是一个高度解耦的流水线网关，通过 LangGraph 管理内部节点流转。它的核心价值在于**将高熵的用户发散请求，降维收敛为机器可执行的具体步骤**。

## 节点拓扑
- **[RECALL] (记忆检索)**：查阅 App 独占的 L3 `memory/`，注回长期上下文。
- **[ARCHITECT] (意图编译)**：扮演主架构师 (Role A)。负责拦截闲聊、提取指令、划定沙盒物理红线，并输出纯粹的 `<blueprint>`（执行蓝图）。
- **[AUDIT] (规则审计)**：系统级滑窗裁剪，保护上下文长度。
- **[EXECUTOR] (自动执行)**：扮演劳工 (Role B)。严格根据 Blueprint 的指导，不再发挥联想，精准通过 MCP 操作环境工具。
- **[REFLECT] (记忆反思)**：侦听架构师是否在思维链留下了 `[PERSIST]` 标记，如有则进行磁盘固化。

## 权限清单 (Manifest)
此应用申请了 `memory`, `fetch_url`, `read_file` 的环境工具读写权限，以及 `app` 级别的内存持久化沙盒隔离权。
