# Chatbot (调试桩)

**定位**：一个纯粹用于链路打通和“人工介入调试”的兜底测试 App。

## 架构职责
在早期的自举阶段，如果大模型的 API 挂了，或者需要人工注入一些异常极端的思维链，我们可以通过启动该应用，人工化身模型进行交互。

## 运行模式
该 App 内部在接收到输入后，会暂停流转，并在终端打印出当前的所有经过 MCP 协议收集到的对话记录 (`【需要复制给模型的上下文】`)。
人类可以手动复制这些文本，拿到网页端的 LLM 产品去生成，然后再把网页端的生成结果粘贴回终端。

## 权限清单
这是一个全暴露无记忆的应用。它声明了 `ephemeral` 的易失性内存，以及最低限度的调试工具 (`echo`, `calculator`)。
