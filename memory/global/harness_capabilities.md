# 系统操作能力与权限 (Harness Capabilities)

- **Created**: 2026-04-25 22:06:00

---

## 🛠️ 当前可用能力 (Logical Capabilities)
- **多步意图编译**：系统支持通过 <thought> 和 <blueprint> 进行任务拆解。
- **持久化认知检索**：系统能从 L3 存储中召回相关的项目事实。
- **跨模型调度**：系统具备平稳降级能力，可自动切换算力提供商。

## 🛡️ 运行时约束 (Runtime Guardrails)
- **非干预原则**：除非明确获得授权，否则不能修改任何系统级配置。
- **物理红线**：架构师不具备直接执行权，必须通过 Blueprint 交由人类中转。
- **隐私边界**：禁止在外部请求中透传系统内部密钥或敏感环境变量。
