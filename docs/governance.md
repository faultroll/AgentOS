# 合规性与系统主权手册 (Governance)

本模块定义了 Harness 的审计标准与主权边界。

---

## 1. 什么是“作弊”
在 Harness 开发中，以下行为被视为作弊：
- 在 `prompts/` 目录下加入特定业务的名称、场景或判定规则（如骰子数值）。
- 在 Harness 内核态 (Kernel Space) 注入针对特定业务 App 的补丁。

## 2. 开发者审计清单 (Pre-Flight Checklist)
在交付前，请自检：
- [ ] **业务中立性**：`kernel/` 和 `prompts/` 目录是否完全业务中立？
- [ ] **语义主权**：修改是否降低了 Role A 的“架构师”地位？
- [ ] **可移植性**：接入一个全新的 App 时，当前的 Harness 核心是否能正常工作？
